# PawTrail illustrated portraits

The canonical workflow is now the independently callable
[PawTrail Portraits](../../pawtrail-portraits/SKILL.md) skill.

Use it for the portrait portion of actor creation or invoke `$pawtrail-portraits`
without creating a gameplay actor. It follows the owner's five steps: inspect the
reference, choose a style and state its prompt, author the artwork and emotions,
animate and visually verify every required state, then complete that style before
starting another. Keep the shared player; make facial performance specific to the
character, style, angle and emotion.

Read its [visual acceptance protocol](../../pawtrail-portraits/references/verification.md)
and [PawTrail integration guide](../../pawtrail-portraits/references/pawtrail-integration.md)
when working on the collection. The earlier V1 Yae Miko Sharp cel export is a failed
motion case, not an approved template. Exact resting PNG matches and changing
frame hashes did not prove that its expressions survived blinking or talking.

This compatibility entrypoint preserves existing actor/cat documentation links.
It supersedes older rotating-3D-bust and generic facial-patch portrait guidance.
Gameplay body rigs remain separate.
