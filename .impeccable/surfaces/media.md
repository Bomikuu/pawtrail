# Media upload

Mode: Operate. Local extension of the approved community journal; code-first.

A labeled file picker leads to previews, a description per attachment, and an explicit upload action. The same form retains failed selections and descriptions for retry. Uploaded files are labeled private. Private PDFs are named documents, never embedded image previews. Image descriptions and remove actions remain keyboard accessible. Six attachments and 10 MiB per file are the clear limits. Controls inherit the canonical Button/Input and DESIGN.md palette, spacing, type and focus behavior.

Preview object URLs are temporary; removing a file or unmounting revokes them. Abandoned private uploads expire after 24 hours unless a domain command attaches them. Publication requires an explicit authorized review. No new visual system or shipping raster assets. F6 owns the complete shared-system audit. Rendered visual quality remains unverified under repository policy.
