# PawTrail interface contract

Achievement ownership: `features/achievements` owns private progress, explicit one-time claims, versioned independent evidence review and opt-in public showcase. Shared `components/ui/progress.tsx` owns progress presentation. Claims/reviews/sharing preserve drafts on failure and have duplicate-submit guards; irreversible approval reversal uses `ConfirmDialog`. The server derives all counters, enforces privacy and appends reward corrections atomically with source changes. Profile badges never expose private proof or application answers. Full earning rules are in `docs/implementation/achievements.md`.

The product requirements and `docs/contracts/django-api.md` own business rules. `DESIGN.md` owns the accepted social/management composition. Existing services, server permissions and moderated public projections remain authoritative.

| Capability            | Canonical owner                                                | Contract                                                                                                                                                                                       |
| --------------------- | -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Navigation shells     | `components/layout/app-shell.tsx`                              | Platform by default; dashboard explicitly selects management. Both fill the viewport width. Management has its own drawer/navigation and a return-to-community link.                           |
| Controls and overlays | `components/ui`                                                | Shadcn-style Slot/CVA Button and Radix Dialog, AlertDialog and DropdownMenu. Feature components use these owners, not duplicate raw controls.                                                  |
| Feed navigation       | `features/community/feed.tsx`                                  | Explicit Load more; scoped following/saved results; nearby requires an area. Failed requests preserve current posts.                                                                           |
| Post creation         | `features/community/post-composer.tsx`                         | Same moderated create/edit operation, retained draft on failure, duplicate-submit guard, inline errors and completion feedback. New/edited media never bypass review.                          |
| Reactions and saves   | `features/community/post-actions.tsx`                          | Existing optimistic update with rollback; visible count comes from the post DTO. Sign-in is required.                                                                                          |
| Deletion              | `components/shared/confirm-dialog.tsx`                         | App-owned protected confirmation; duplicate guard; failure stays actionable.                                                                                                                   |
| Feedback              | `components/ui/sonner.tsx`, `components/shared/data-state.tsx` | One toast provider; important form errors remain inline; explicit loading, empty and retry states.                                                                                             |
| Search                | `features/search/global-search.tsx`                            | 300ms debounce, composition-safe input, cancelled superseded work, arrow/Escape navigation, immediate clear and focus restoration. Committed search uses the existing URL-based results route. |
| Media                 | `components/shared/animal-image.tsx`                           | Private/sensitive safeguards remain. Compact fallback is an accessible icon, never an invented photograph.                                                                                     |
| Scrollbars            | `app/globals.css`                                              | One visible global token baseline, forced-color fallback, stable document gutter. Desktop sidebars can scroll; task documents retain natural height.                                           |

Locale stays en-PH with Asia/Manila dates and integer PHP centavos. New artwork is decorative and receives empty alt text; data photographs keep their existing descriptions. Icon-only navigation/actions carry explicit accessible names. No new payment, permission, deletion or adoption policy is introduced here.

People avatars use the curated catalog in `features/users/avatar-presets.ts`, the controlled `AvatarPicker` inside the existing profile form, and the shared `CommunityAvatar` renderer. Selecting previews a choice; **Save profile** commits it with the other profile fields. Failure preserves the draft. Successful saves refresh queries and update only the same session actor's display name/avatar, preserving roles and account scope. Existing identifiable people get stable defaults; hidden attribution never receives a stable identifying avatar. Arbitrary media still follows publication review.

No automated tests, type/UI checks, builds or rendered browser verification were run for this redesign, following the user's standing instruction. These are implementation contracts, not a conformance claim.
