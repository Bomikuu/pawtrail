# Animal medical records implementation plan

Extend existing pet profiles and animal management with a Medical section, preserving current identity, role, media, version and publication boundaries. Do not touch standalone game rendering, 3D players/cats or their assets.

1. Add persisted medical records and immutable revision/document references. Allow only existing caretakers, responsible shelter staff and administrators to write. Keep private notes/provider/document data out of public DTOs; sharing requires a separate public summary. Dates/status are entered, never inferred. No veterinary verification, vaccination schedule or reward is generated.
2. Extend the real typed API/BFF with scoped list/create/update operations and private media authorization. Retain idempotency, expected versions, atomic updates and attachment-use protection. Unconnected adapters return unavailable rather than clinical fixtures.
3. Add a server-rendered Medical profile tab and a private dashboard record book with explicit planned/performed states, dates, vaccine metadata, private documents, sharing, corrections, archive/restore and history. Use actual official shadcn components, Tailwind, existing fonts and management/public shells.
4. Apply the migration to the actual local database without seeding clinical history. Capture desktop/mobile rendered screenshots in Firefox, including the truthful empty state and blank entry form. Use one batched visual review/fix cycle and at most one confirmation pass. Do not run a broad test suite or production build.
5. Use Impeccable through its documented direct-context fallback and Jev through the available CLI. Submit only generic design/permission summaries to Jev. Record results and any denied/pending/uncertain operations precisely.

Completion: implementation and local migration are complete. Firefox captured the actual desktop/mobile empty profile and unsaved editor; the selected mobile tab is visible. No clinical records were created. Direct self-review replaced delegated reviewers under the no-agents instruction. Details, Jev results, artifacts, check limitations and resolved wrapper permission issue are documented in `animal-medical.md`. The final repository UI boundary check passed; the earlier unrelated model-workshop violation was resolved by concurrent work. This task did not modify 3D files. Clinical mutation E2E tests were not run.
