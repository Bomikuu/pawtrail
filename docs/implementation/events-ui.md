The supplied event-detail screenshot guides the new full-width two-column composition. The illustrated cover comes from the owner's existing eight-banner collection, with no new bitmap assets. The public host resolves to the visible shelter or consenting organizer. Management eligibility comes from the same permission function as the existing event update path. List responses keep summary-only projections rather than computing full attendee details for every card.

Sharing uses native sharing, clipboard, then an explicitly selectable URL. Public-venue Maps links open only after the user activates them. They do not reveal animal sighting coordinates.
