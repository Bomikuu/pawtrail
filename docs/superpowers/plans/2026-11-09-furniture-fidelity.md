# Furniture fidelity and rotation controls

**Goal:** Match the original couch's rounded silhouette and paired floral pillows, slightly enlarge/detail the furniture, author real curtain/aquarium models and put a circular rotate action above selected furniture.

**Approach:** One shared model kit, per-kind geometry and projected contacts; uniform 96×112 native cells with larger physical silhouettes. Export four facings, style variants, model GLBs and native cloth/fish animation frames. Use these models in the creator/comparison and generated frames in the live room. Retain item IDs and existing inventory; no fixture grants.

**Work:** Author models and contacts; generalize exporter/renderer; add item selectors and above-object controls; consume native reactive frames in Homes and the local interaction field; update skill/docs and mirror scoped files. Art production uses isolated Firefox; no application tests, builds or browser verification under standing owner instructions.
